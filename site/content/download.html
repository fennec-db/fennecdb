Download fennecdb

Two programs, fennec-server and the shell fennec, as a download for your machine, and a package for each language that reaches them. One command puts both in your home directory, with no sudo.

macOS on Apple silicon and Intel · arm64 and x86_64

curl -fsSL https://fennecdb.com/install.sh | sh

Puts fennec-server and fennec in ~/.fennecdb/bin and edits no shell file: it prints the line that puts them on your PATH. Read it before it runs: install.sh.

Homebrew

brew install fennec-db/tap/fennecdb

The release's own binaries, checked against their SHA-256. brew upgrade fennecdb takes the next release.

aarch64-apple-darwinx86_64-apple-darwin

A folder holding the two programs: nothing needs installing, run them from there.

Puts both programs in ~/.fennecdb/bin, no sudo, and edits no shell file. It needs curl, or a wget that checks certificates.

Anywhere Docker runs · amd64 and arm64 · fennec-server alone, 7 MB

docker run -d --name fennecdb -v fennecdata:/data \
  -p 127.0.0.1:8080:8080 -e FENNEC_HTTP_TOKEN=a-token \
  ghcr.io/fennec-db/fennec-server:{{version}}

No shell and no libc in the image. Its data lives in /data, kept here in a volume. A container listens beyond localhost, so the server asks for a token. Run it in a container has the rest.

What the one command does

It asks GitHub for the latest release over https, checks your machine's tarball before it unpacks anything, and puts the two programs where you can see them. What you watch here is what install.sh prints.

  • No sudoYour home directory, and no shell file edited: it prints the PATH line and leaves that to you.
  • Checked before it is unpackedAgainst the release's SHA256SUMS. That sum comes from the same release as the file, so it catches a damaged or cut-short download, not a release someone replaced.
  • Nothing runs till its last lineThe script is functions, started by main "$@" at its end, so a download cut short runs nothing.
  • Gone in one lineTo remove it, delete ~/.fennecdb. To pin a release, FENNEC_VERSION={{version}}.

What you get

The same engine in each: the server's file, the shell's, the one in a page and the one in an app are one format.

fennec-server

HTTP and JSON, from every language

The server: one file is one database, with live queries, sync to devices, search, rules and tenants, and HTTPS of its own.

fennec

the shell, over a .fennec file

Opens a file and runs FennecQL or SQL's everyday spellings, and imports SQLite and PostgreSQL.

ghcr.io/fennec-db/fennec-server

7 MB the image, amd64 and arm64

fennec-server alone: no shell, no libc, its data in /data.

@fennecdb/web

338 KB of gzipped WebAssembly with no dependencies

The client, and the database in a page: the same match, typos and facets, offline.

Check it, or build it

Check a download

curl -LO https://github.com/fennec-db/fennecdb/releases/download/v{{version}}/SHA256SUMS
shasum -a 256 -c --ignore-missing SHA256SUMS
# Linux: sha256sum -c --ignore-missing SHA256SUMS

A release lists every file with its checksum in SHA256SUMS; the release page lists the files.

From source, and the studio's desktop app

For a build the releases do not have, clone the repository and build with cargo and make: Build from source.

fennec studio's desktop app (beta) is a window on the studio a fennec-server serves, one server per file. It is built from the repository with make studio-desktop: Desktop app.
